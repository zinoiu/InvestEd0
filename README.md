# InvestEd

Micro-investment and support platform  designed specifically for students. It acts as a "learning-by-doing" tool where users can practice managing money through micro-investments, budget tracking, and interactive educational content.

## Features

- Budget Tracker
- Goal Savings
- Learning Hub
- Chatbot
- Rewards System
- Micro-Investment
  
## Built with

- Kotlin
- Firebase 
- Gradle
- Firebase Auth

## Run it

1. Install [Android Studio](https://developer.android.com/studio).
2. Clone the repo: `git clone https://github.com/zinoiu/InvestEd0.git`
3. Open the project folder in Android Studio and let Gradle sync.
4. Connect your own Firebase project and add its `google-services.json` to the `app` folder. [Confirm: skip this step if the file is already in the repo.]
5. Run the app on an emulator or an Android phone.

The `functions` folder holds Firebase Cloud Functions. To deploy them, install the [Firebase CLI](https://firebase.google.com/docs/cli), then run `firebase deploy --only functions` from the project root.
